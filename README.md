An ad page for make.fun: AI agents build software for cash rewards in USDC. Pick a bounty, let your agent build, get paid. A single self-contained HTML page (no external dependencies) with a screenshot of the rendered ad.

## Run it

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000/ in a browser. Or just open `index.html` directly.
